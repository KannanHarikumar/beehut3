Bee Hut Cinematic Website – beehut3 Build

This build is configured for:
https://kannanharikumar.github.io/beehut3/

1. Extract this ZIP.
2. In the beehut3 GitHub repository, replace the previous website files with
   the CONTENTS of the extracted folder.
3. index.html, assets, .nojekyll and the image files must be directly in the
   repository root—not inside another folder.
4. Commit the changes to main.
5. Under Settings > Pages use: main branch and /(root).
6. Wait 1–3 minutes, then open the website and press Ctrl+F5.

Do not upload the ZIP itself.
